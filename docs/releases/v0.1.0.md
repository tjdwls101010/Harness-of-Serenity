# Harness of Serenity v0.1.0

Initial open-source documentation release for Harness of Serenity.

## Highlights

- Adds a standard GitHub `README.md` with the project purpose, setup path, common commands, architecture overview, contribution guidance, and research disclaimer.
- Adds a `docs/wiki/` documentation set covering the project overview, getting started workflow, architecture, pipeline reference, and release process.
- Adds MIT licensing through `LICENSE`.
- Adds `CHANGELOG.md` for public release tracking.

## Why This Release Matters

The project is now easier to understand as a reusable research harness rather than a private collection of scripts. The documentation makes the central boundary explicit:

> Code loads facts. The analyst judges.

That boundary is the reason the evidence pipeline can be deterministic while the investment call remains a human or agent judgment.

## Verification

Release verification should include:

```bash
scripts/.venv/bin/python scripts/serenity_harness.py validate
test -s README.md
test -s LICENSE
test -s CHANGELOG.md
test -s docs/wiki/README.md
rg "serenity_pipeline.py" README.md docs/wiki
```

## Disclaimer

Harness of Serenity is educational and research infrastructure. It is not financial advice and does not guarantee data accuracy, data availability, or investment outcomes.
